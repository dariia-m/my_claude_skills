# Calques and Russisms: substitution tables

Reference for Pass 2 (Lexicon). Columns: what to find → what to write. Context notes where the fix depends on meaning. Frequency matters: a single mild item in a long text may stand; repeated items are a pattern and must go.

| Русизм | Українською |
|---|---|

| по причині | через, з огляду на |
| по результатам | за результатами |
| по замовчуванню | за замовчуванням, типово |
| заходи по боротьбі | заходи для боротьби / заходи проти |
| по спеціальності | за спеціальністю, за фахом |

| робота по вивченню | робота з вивчення |

## 3. Active participles in -учий/-ючий/-ачий/-ячий

Un-Ukrainian as attributive adjectives. Standard repairs: (a) established adjective, (b) який-clause, (c) noun.

| Найдено | Заміна |
|---|---|
| існуючий | наявний, чинний |
| діючий (закон) | чинний (закон) |
| працюючий | який працює; працівник |
| зростаючий (попит) | щораз більший, дедалі вищий (попит) |
| оточуючий | навколишній, довколишній |
| оточуюче середовище | довкілля |
| початкуючий | початківець |
| виступаючий | доповідач, промовець |
| керуючий | керівник; який керує |
| відповідаючий вимогам | який відповідає вимогам; відповідний |
| обслуговуючий персонал | обслуга; персонал з обслуговування |
| домінуючий | домінантний, панівний; який домінує |

Passive participles in -ний/-тий and adjectives in -лий (зів'ялий, застарілий) are fine - do not touch.

## 4. Nominalization chains (канцелярит)

Verbal-noun stacks read as bureaucratese in any provenance. Unwind to verbs:

| Канцелярит | Природно |
|---|---|
| здійснити оцінювання впливу | оцінити вплив |
| проводити аналіз даних | аналізувати дані |
| виконувати перевірку | перевіряти |
| забезпечити виконання плану | виконати план (if that is the meaning; "забезпечити" only when the subject enables someone else's action) |
| з метою покращення | щоб покращити |
| шляхом застосування | застосувавши; через |
| у процесі розробки | під час розробки; розробляючи |
| в рамках проєкту | у межах проєкту; за проєктом; often just delete |
| питання щодо можливості надання | чи можна надати |
| відбувається зростання | зростає |
| має тенденцію до зниження | знижується; зазвичай знижується |

Rule of thumb: if a sentence has two or more verbal nouns hanging off one weak verb (здійснювати, проводити, забезпечувати, виконувати, відбуватися), rewrite around one strong verb.

## 5. Copula and existential padding

| Найдено | Природно |
|---|---|
| Це є важливим | Це важливо |
| є свідченням того, що | свідчить, що |
| є можливим | можливо; можна |
| існує ймовірність, що | імовірно; може |
| існує потреба в | потрібно |
| має важливе значення | важливий; важить |
| має можливість | може |
| в наявності є | є |

"Є" is not banned - Ukrainian keeps it where the sentence otherwise collapses ("Це є і буде нашою метою"). The target is padding, not the word.
